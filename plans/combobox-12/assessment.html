Assessment: Combobox wrappers

Scope Intake

Desired outcome: expose Live Wires’ merged optional single-select combobox contract through CSS-free Templ wrappers and a maintained gallery example.

Approved constraints: the user’s implementation request and acceptance list in this session; issue #12; exact trusted base 284684633bcc5e026155b62fe5a1c21541f49099; producer merge 5db085d2918375811ee30562bc4229b414f314e4. Native select owns submission and validation. Keep JavaScript and CSS external.

Mechanism: add a Props component with root and native-select attribute seams plus convenience wrappers; render the producer’s stable root/select hooks and accessible hint/error wiring. Demonstrate local and application-simulated remote search in the maintained gallery.

Future/conditional: Baseplate adoption is a handoff only. No member-search endpoint, migration, release, or consumer rollout.

Project Alignment

  • Goal: provide reusable Go/Templ components that emit Live Wires markup without shipping CSS or JavaScript.
  • Evidence: repository CLAUDE.md; issue #12; Live Wires producer docs/reference at 5db085d2918375811ee30562bc4229b414f314e4; merged gallery PR #19 at base.
  • Fit: wraps an existing framework control contract and demonstrates it using the already-maintained local gallery.
  • Ownership: this repository owns component markup and the gallery adapter. Live Wires owns the optional assets. Baseplate owns its timezone field, validation and saved-value behavior.
  • Non-goals: multi-select; a second state machine; bundled assets; production endpoint; Baseplate changes; release or merge.
  • Coordination: producer PR #32 is merged; main contains gallery PR #19. The task branch is isolated. The old clean gallery worktree is preserved.
  • Unknowns: none block implementation. Verify all asset hashes at the exact compatible producer revision and keep the API consistent with existing form patterns.

Key Requirements

  1. Provide additive Props and convenience APIs with explicit IDs, label, options, selected value, hint, server error, required, disabled and form association.
  2. Preserve existing Select API and required-indicator behavior; avoid textarea-hint scope.
  3. Put caller attributes on the actual native select through the canonical InputAttrs seam; preserve developer-controlled wrapper attributes.
  4. Keep one native select as the only named successful control; the external enhanced search input has no name and never changes submitted values while typing.
  5. Preserve empty optional defaults, required placeholder validation, selected labels/values absent from search results, and no-JavaScript native fallback.
  6. Keep CSS/JS external and application-owned. Do not add search, authorization, validation, persistence or save behavior to this library.
  7. Test escaping, IDs/instances, selected options, hint/error wiring, attributes, and compatibility.
  8. Add a stable gallery route with local and simulated remote search, deterministic delay/error/out-of-order controls, and fallback; pin compatible assets by exact revision and verified hashes.
  9. Run Docker-only generation/tests/vet, gallery verification, and source-bound desktop/mobile browser checks. Preserve evidence and state synthetic composition/DOM limits accurately.
  10. Document the Baseplate Timezone override candidate and empty-string/non-curated-value semantics without changing Baseplate. Keep the PR unmerged and do not tag or release.
