Research Brief: Combobox wrappers

Summary

The upstream single-select contract is merged and already defines the complete browser behavior. Templ should render its stable native markup and accessibility relationships only; the optional Live Wires CSS/JS remains an external asset pair.

Project Context

Trusted base is 284684633bcc5e026155b62fe5a1c21541f49099. Gallery PR #19 is merged on main. Live Wires PR #32 is merged at producer commit 5db085d2918375811ee30562bc4229b414f314e4; issue #18 remains open, but its producer is merged and the library dependency is clear at the required source level.

Domain Knowledge

The native select owns the only submitted name/value, required and custom validity, disabled/fieldset/form association and reset semantics. Typing/highlighting never commits. External enhancement preserves selected labels and saved values absent from search results. Remote results are application supplied and request identity is handled by the producer, not Templ.

Design References

Use the merged reference markup at public/reference/forms/combobox.html. Preserve the visible label, hint/error relationship, native fallback and producer's data-combobox root. The local example can use Live Wires' existing field, hint, error and button styles; add no component CSS.

Technical References

  • Merged combobox contract
  • Merged reference markup
  • Producer controller source
  • Producer query-state source
  • Producer state tests and producer browser cases

Codebase Patterns

form.Select supplies the required-indicator and field wiring patterns but remains unchanged. controlID, hintID, errorID and describedByAttrs are already available. Templ component packages use Props with Class/Attrs and generated *_templ.go. The gallery already has named routes, a stable asset lock, app-owned demo.js, full native fallback coverage and Playwright tests.

Constraints and Risks

  • Do not hide or replace the native select with a second named input or formdata shim.
  • Make IDs deterministic and explicit for both the enhancement root and control; do not rely on duplicate field names for multiple instances.
  • Put caller attributes on the actual select through a dedicated seam and preserve root Attrs separately.
  • Keep error text escaped by Templ and wire hint before error in aria-describedby.
  • Update and verify every existing asset hash if the lock moves from cf6ef2e to the exact merged producer revision.
  • Browser DOM/composition emulation does not establish physical IME or screen-reader behavior.

Key Decisions Needed

No unresolved owner decision. Use ID for the native select and RootID for the stable wrapper, with explicit options and an optional Props value; use the repository's canonical InputAttrs seam on the native select while root Attrs remains on the wrapper. The remote example is local simulation only, with fixed delays and error/out-of-order choices.
